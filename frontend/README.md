# Expo Frontend

This folder contains the Expo mobile app for the FYP project.

## Setup

1. Create a `.env` file from `.env.example`.
2. Set your Clerk publishable key.
3. Set `EXPO_PUBLIC_API_URL` to your backend URL.
4. Run `npm install` inside this folder.
5. Start the app with `npm run start`.

## Notes

- Authentication uses Clerk.
- The backend should validate Clerk session tokens.
- Add your app screens, navigation, and API calls here.
